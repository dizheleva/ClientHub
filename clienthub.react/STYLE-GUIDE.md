# 🎨 Ръководство за стилове - ClientHub

## Как да използваш различните стилове

Създадени са **5 различни варианта** на стилизация. За да използваш един от тях:

### Стъпка 1: Отвори `src/main.jsx`

### Стъпка 2: Промени импорта на CSS файла

Намери реда:
```jsx
import './styles.css'
```

И го замени с един от следните варианти:

---

## 📋 Варианти

### ✅ Вариант 1: Модерен минималистичен (Modern Minimal)
**Препоръчителен за:** Универсална употреба, професионален вид

```jsx
import './styles-modern-minimal.css'
```

**Характеристики:**
- Чист и модерен дизайн
- По-добри spacing-и и типография
- Меки цветове и градиенти
- Добри hover ефекти
- Професионален вид

---

### 🌙 Вариант 2: Тъмен режим (Dark Mode)
**Препоръчителен за:** Работа в тъмно, модерен вид

```jsx
import './styles-dark-mode.css'
```

**Характеристики:**
- Тъмен фон с ярки акценти
- По-добро за очите при работа в тъмно
- Модерен и стилен вид
- Неонови ефекти и светене

---

### ✨ Вариант 3: Glassmorphism (Застъклен ефект)
**Препоръчителен за:** Модерен, визуално привлекателен вид

```jsx
import './styles-glassmorphism.css'
```

**Характеристики:**
- Прозрачни/застъклени карти
- Blur ефекти
- Ярки цветове с прозрачност
- Много модерен визуален стил

---

### 💼 Вариант 4: Професионален бизнес (Corporate)
**Препоръчителен за:** Корпоративна среда, формален вид

```jsx
import './styles-corporate.css'
```

**Характеристики:**
- По-формален и корпоративен вид
- Консервативни цветове
- Добра типография
- Структуриран layout

---

### 🎨 Вариант 5: Ярък градиентен (Vibrant Gradients)
**Препоръчителен за:** Енергичен, младежки вид

```jsx
import './styles-vibrant.css'
```

**Характеристики:**
- Ярки цветове и градиенти
- Анимиран фон
- Забавни анимации
- Младежки и енергичен стил

---

## 🔄 Как да смениш стила

1. Отвори `clienthub.react/src/main.jsx`
2. Намери реда `import './styles.css'`
3. Замени го с един от вариантите по-горе
4. Запази файла
5. Приложението автоматично ще се обнови

## 💡 Препоръки

- **За бизнес приложение:** Вариант 1 (Modern Minimal) или Вариант 4 (Corporate)
- **За модерен вид:** Вариант 2 (Dark Mode) или Вариант 3 (Glassmorphism)
- **За забавление:** Вариант 5 (Vibrant)

## 📝 Забележка

Оригиналният `styles.css` файл остава в проекта. Можеш да се върнеш към него по всяко време.
